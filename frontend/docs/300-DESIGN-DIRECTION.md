# Design Direction

## Position

Professional, calm, scientific and enterprise-ready.

Victus should not look like:

- generic AI SaaS
- wellness app with bright green UI
- futuristic dashboard
- medical legacy software

## Light palette source

```txt
#134611
#3e8914
#3da35d
#96e072
#e8fccf
```

Use green cautiously. It should not dominate every surface.

## Dark palette source

```txt
#161925
#23395b
#406e8e
#8ea8c3
#cbf7ed
```

This is stronger for enterprise/demo mode because it feels more institutional and less like a wellness app.

## Motion usage

Use Motion for:

- message entrance
- typing indicator
- evidence card reveal
- rail trace changes
- button press feedback

Avoid:

- decorative movement
- background animation
- floating particles
- glowing AI states
